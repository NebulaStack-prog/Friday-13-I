## Часть 1. Основной документ.

### 1. Заголовок и базовая информация.

• **Название:** Friday 13 – I.

• **Назначение:** Проект № 2. Продукт.

• **Фаза проекта:** Phase I.

• **Технологический стек:** Python

• **Статус проекта:** Полностью завершен.

### 2. Краткое описание проекта.

Проект "Friday 13 - I" переплетает в себе модель классической пиксельной игры "Змейка" и атмосферу известной многим пятницы 13-го.

Задачей игрока является заполнить все игровое поле телом змейки, поедая "Туристов", выступающих классическими "яблоками".

Проект включает в себя три разных уровня по размерам клеток поля: 8×8, 12×12 и 16×16, каждый из которых рекомендован к прохождению.

Змейка имеет окрас эмблемы NebulaStack Friday 13.

### 3. Четкие цели проекта.

• Преобразовать классическую версию змейки.

• Пополнить витрину проектов NebulaStack и продемонстрировать подход к классическим играм IT индустрии.

• Создать атмосферу Пятницы 13-го для полного погружения.

• Реализовать основные игровые механики: движение и поворот змейки, удлинение хвоста при поедании цели, появление новых целей, отображение полученных очков.

• Создать играбельную модель с понятным управлением и интерфейсом.

### 4. Компоненты проекта.

• Скрипты для движения змейки, ее удлинения, для появления "Туристов" и т.д.

• Основные инструменты-объекты: прямоугольники, цвета, функции (библиотека Pygame).

• Вся собранная игра находится в едином файле Friday13-I.py.

### 5. Инструкция по использованию.

**5.1. Использование:**

• Для работы необходимо запустить код в Python или открыть исполняемый файл ".exe".

• После запуска игры нажимайте на клавишу с номером уровня (1, 2 или 3) и выбирайте уровень сложности по размеру карты.

• Вашей задачей является заполнение всей карты телом змеи за счет его увеличения.

• Увеличить тело можно поедая цели, которые появляются на карте в рандомных местах.

• Игра завершается если змейка коснулась своего тела либо стены (Экран "GAME OVER"), после нажатия на "R" (Restart) появится главный экран с выбором уровня, после нажатия на "ESC" игра полностью закроется.

**5.2. Управление:**

• Стрелка ВЛЕВО (←): начать движение влево.

• Стрелка ВПРАВО (→): начать движение вправо.

• Стрелка ВНИЗ (↓): начать движение вниз.

• Стрелка ВВЕРХ (↑): начать движение вверх.

• ESC во время игры: возврат в главное меню выбора уровня.

• ESC на экране GAME OVER: полный выход из игры.

• R на экране GAME OVER: возврат в главное меню.

• Важное примечание: змейка не может разворачиваться на 180° и начинать движение "в своем теле". Также змейка не должна врезаться в свое тело и в стены карты.

## Часть 2. Технический документ.

### 1. Цели разработки.

• Создать играбельную версию классической "Змейки" с тематическим оформлением "Пятница 13-е".

• Реализовать систему уровней сложности с разными размерами поля и скоростью игры.

• Обеспечить корректную обработку столкновений и регенерацию еды вне тела змейки.

### 2. Использованные технологии.

• **Языки программирования:** Python.

• **Библиотеки:** pygame, random.

### 3. Архитектура проекта.

• Проект использует процедурную архитектуру с разделением на функции.

• Функция show_menu() – отвечает за отображение главного меню, выбор уровня и возврат параметров сложности в виде словаря.

• Функция game(level) – основной игровой цикл, принимает параметры уровня и управляет всей игровой логикой.

• Внутри функции game() определены вложенные функции: score() для отображения счета, message() для вывода сообщений, tourists() для отрисовки цели.

• Глобальные константы определяют цвета, параметры уровней и шрифты.

• Точка входа: вызов show_menu() и передача результата в game().

### 4. Структура проекта.

• Проект состоит из одного основного файла: Friday13-I.py.

• В этом файле находится весь код: инициализация pygame, константы, функции меню и игры.

• Для работы требуется установленная библиотека Pygame (pip install pygame).

• Импорт модулей (pygame, random)

• Инициализация pygame

• Определение цветов (black, white, dark_red, blood_red, grid_gray)

• Словарь levels с параметрами трех уровней

• Настройка шрифтов

• Функция show_menu()

• Функция game(level) с вложенными функциями и игровым циклом

• Запуск игры через show_menu() и game()

### 5. Ключевые компоненты системы.

• **Словарь levels** – хранит параметры каждого уровня: grid_size (размер сетки 8/12/16), cell_size (размер ячейки 45/40/35), speed (скорость игры 6/8/10), name (название уровня).

• **Игровое поле** – дискретная сетка, где координаты объектов всегда кратны cell_size.

• **Змейка (snake_list)** – список координат сегментов тела, length_of_snake – текущая длина.

• **Движение** – реализовано через переменные x1_change и y1_change с запретом разворота на 180°.

• **Проверка столкновений** – со стенами (выход за границы поля) и с собственным телом (сегменты списка snake_list).

• **Поедание цели** – при совпадении координат головы (x1, y1) и еды (foodx, foody) длина увеличивается на 1, еда регенерируется в случайную свободную клетку.

• **Система рестарта** – при game_close через клавиши R (возврат в меню) и ESC (выход).

• **Визуальная стилизация** – голова змейки рисуется с глазами и кровавыми линиями, тело с крестообразными разрезами и красными пятнами, туристы в виде кругов с глазами.

### 6. Реализация пользовательского интерфейса.

• Меню выбора уровня создается через функцию show_menu() в отдельном окне 800×600.

• В меню выводится название игры красным цветом и четыре опции: три уровня и выход. Выбор осуществляется клавишами 1, 2, 3, ESC.

• Игровое окно имеет динамический размер, зависящий от уровня: ширина и высота = grid_size × cell_size.

• В левом верхнем углу игрового окна отображается счет: "Victims: N" кроваво-красным цветом.

• На поле рисуется серая сетка с шагом cell_size для визуального разделения клеток.

• При game_close по центру выводится сообщение "GAME OVER! ESC - Exit, R - Replay" красным цветом.

• Все визуальные элементы создаются через функции pygame.draw (прямоугольники, круги, линии), без использования загруженных изображений.

### 8. Основные сложности и способы их решения.

• **(1) Сложность:** еда появлялась внутри тела змейки, что делало игру нечестной.

**Решение:** при регенерации еды добавлен цикл while True, который проверяет, не находится ли новая координата в snake_list, и генерирует новую позицию до тех пор, пока не найдется свободная клетка.

• **(2) Сложность:** змейка могла мгновенно развернуться на 180 градусов и врезаться в свое тело.

**Решение:** перед изменением направления добавлена проверка: при нажатии влево разрешать движение только если x1_change == 0 (змейка не движется вправо), и аналогично для всех направлений.

• **(3) Сложность:** разная скорость игры и размер поля на разных уровнях требовали гибкой настройки.

**Решение:** все параметры уровня вынесены в словарь levels, а функция game(level) динамически подстраивает окно, размер блоков и FPS через clock.tick(snake_speed).

• **(4) Сложность:** визуальные элементы (глаза, линии) выглядели некорректно при маленьких размерах ячеек.

**Решение:** для всех размеров используется max(1, значение // делитель), что гарантирует минимальный размер от 1 пикселя и предотвращает ошибки отрисовки.

• **(5) Сложность:** после game_close игрок не мог начать новую игру без перезапуска.

**Решение:** добавлен внутренний цикл while game_close, который ожидает нажатия R (вызов show_menu() и рекурсивный вызов game()) или ESC (выход).

### 9. Текущие ограничения проекта.

• Весь код находится в одном файле, что может усложнить дальнейшее расширение и поддержку.

• Отсутствует режим победы (заполнение всего поля телом змейки), игра заканчивается только поражением.

• Нет сохранения рекордов или лучших результатов между запусками.

• Полностью отсутствует звуковое сопровождение (музыка, звуки поедания, проигрыша).

• Все цвета и параметры уровней жестко закодированы, изменение требует правки исходного кода.
